# 本地模拟 ATS 回归测试

## 目的

验证受控投递工作流的最小页面契约：普通字段可映射、未知敏感字段可识别、最终提交默认禁用，且模拟页面不向网络发送数据。

## 静态检查结果

- 普通字段存在：`name`、`phone`、`email`、`graduation_date`、`self_intro`、`resume`。
- `salary` 具有 `data-sensitive="true"` 标记，且页面明确提示自动化应在此暂停。
- “最终提交（本地模拟）”默认 `disabled`，仅本地测试确认框勾选后才启用。
- 提交处理逻辑拒绝薪资字段非空的状态。
- 未发现 `fetch`、`XMLHttpRequest` 或 `sendBeacon`，因此页面不产生网络请求。

## 浏览器交互限制

尝试通过受控 Chrome 打开本地 `file://` 页面时，被浏览器 URL 安全策略拒绝。没有尝试通过本地服务器、CDP 或其他方式绕过该策略。真实官网的只读预检已单独完成并记录在岗位目录的 `browser-preflight.md`。

## 结论

本地 fixture 满足提交闸门和敏感字段暂停的静态契约。真实表单填写仍必须在有效批准清单、用户登录和两次即时确认下进行。
