# 评测

1. 单元：路径越界、证据映射、未知/敏感答案、URL 中有效岗位 hash 保留、状态转换、重复回执、批准哈希变化。
2. 扩展：运行上游 Node 测试；新增独立扫描/填写协议测试，检查旧快照、已有值冲突、只读日期、radio/select、动态经历。
3. 本地 E2E：使用假资料及本地模拟 ATS，实际启动 Chromium 和扩展，走多页→附件→摘要→用户确认记录→提交→脱敏回执；检查最终确认缺失、重复提交、暂停恢复、提交未知、后台重启。
4. MCP：真实 stdio 客户端初始化、listTools、工具参数校验和最小工作流。
5. 真实站点：完美世界 Moka、灵犀互娱阿里校招、游卡逐一记录；登录与真实投递须用户参与，不将 mock 结果计作真实兼容。
6. 完美世界进入表单：已确认岗位详情页“申请职位”按展开操作执行；错误域名、其他租户/岗位/路由、已有申请字段、表单或弹窗内按钮、原生 submit 控件均不得使用此例外。最终提交门禁仍须回归。

通过标准：类型检查、上游回归及新增自动测试全部通过；无未授权点击/上传；填写值可追溯；无重复提交；任何未验证项明确保留。真实岗位关闭、清单过期或缺少登录时记录阻断，不规避。
