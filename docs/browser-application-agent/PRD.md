# Codex 网申执行器 PRD

范围与实施授权：用户于 2026-09-23 明确要求实施《Codex 网申填写工具改造方案》。本组文档是该已确认方案的落地，不另增审批轮次。

## 用户与流程

面向当前 Windows 求职工作区。Codex 读取已批准岗位材料，通过本地 MCP 启动可见 Chromium、加载扩展与结构化答案，用户登录后连续填写、添加经历、翻页、上传。最终摘要经用户明确确认后只提交一次，取得回执才记 submitted。

输入：jobs/approved 下的有效不可变清单、绑定原文证据的结构化答案、用户授权记录。输出：填写结果、阻断原因、检查点、脱敏回执。无需额外模型 API Key，不手动导入插件简历。

## 边界

单用户、单浏览器、串行岗位；最终提交是操作批准的唯一人工关口。必要的前置按钮、协议及流程确认按根目录 AGENTS.md 的“快速通道交互授权（2026-09-24）”由 Agent 判断并直接推进。验证码、必须本人完成的身份验证及缺失真实答案只请求必要接管或补充；官方招聘/SSO 跨域核实关联后继续。不生成简历、不修改事实库、不推进 resume_content。真实网站适配以实测结果为准。

普通资料授权可以复用同一网站、字段和用途的已记录明确批准。开放题及敏感答案不得由工具自由生成。最终提交确认独立于材料批准。
