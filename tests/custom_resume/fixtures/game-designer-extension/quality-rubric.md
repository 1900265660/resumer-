# 游戏策划五方向评分卡

先判真实性和方向所有权，再评分；真实性失败不能由行业亲和或质量分抵消。

- `jd_coverage`：主方向设计动作、产物和验证由直接事实或诚实能力边界处理。
- `selection_quality`：主方向直接证据优先，玩家、内容、本地化、MOD 或 QA 不被抬为策划所有权。
- `evidence_depth`：核心经历包含个人设计决策、规格/实现边界、验证方法和可信结果。
- `hr_scan`：10 秒内能识别系统、战斗、文案、叙事或综合主方向及可追问边界。
- `language_naturalness`：中文具体克制，不用“策划思维”或宽泛 Owner 术语代替事实。

新流程每项至少 8 分；HR Reviewer 必须为 `strong_push`，总分至少 9.0、六维至少 8.0，并通过字符型内容充实度门禁。
