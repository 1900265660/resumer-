# Custom Resume V1 固定盲评评分卡

先判真实性，再评分。真实性失败不能被质量分抵消。

- `jd_coverage`：衡量输出是否负责处理 JD，而不是候选人是否已经胜任。8 分表示所有高优先级要求都有精确事实证据，或由一条清晰、诚实的能力边界覆盖核心缺口。已明确披露的缺口不得因为“没有该经历”再次扣分；未披露的高优先级缺口应低于 8。
- `evidence_depth`：8 分表示核心经历能看到候选人的动作、方法或交付物，以及事实支持的结果；不得补写用途、因果、所有权或结果。
- `hr_scan`：8 分表示仅阅读四板块正文，10 秒内能识别三项最相关优势和主要风险。内容 Agent 不负责姓名或目标岗位横幅，不得因缺少横幅扣分。
- `language_naturalness`：8 分表示中文具体、克制、连贯，没有机械拆分、标签堆叠、模板腔或审计报告口吻。一条简洁的能力边界是正常简历内容，详细缺口分析应留在验收报告。

经历标题中的公司、角色和日期直接与事实快照对应 `experience_id` 的标题核验，不要求在 bullet trace 中重复引用。每个 Markdown bullet 必须由其 trace 中列出的同经历 `fact_ids` 完整支持。
