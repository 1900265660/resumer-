# Game Production PM 扩展盲评评分卡

先判真实性，再评分；真实性失败不能由质量分抵消。

- `jd_coverage`：8 分表示版本规划/拆解、排期与依赖、跨职能透明、风险/流程、团队产能和游戏体验等高优先要求均由直接事实或一条诚实能力边界处理。
- `evidence_depth`：8 分表示核心证据包含个人动作、项目机制或交付物及事实支持的结果；活动项目不得冒充游戏版本管线，排班不得冒充产能或人效分析。
- `hr_scan`：8 分表示 10 秒可看到项目交付、游戏证据和主要缺口，不要求姓名或目标岗位横幅。
- `language_naturalness`：8 分表示中文具体克制，无机械标签、审计报告腔或游戏行业黑话堆砌。

经历标题直接对照事实快照相同 `experience_id` 的标题。每个 Markdown bullet 必须由 trace 中同经历的 `fact_ids` 完整支持。
